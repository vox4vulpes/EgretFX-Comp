    This browser can't run Egret Comp (it needs AudioWorklet). Try a current Chrome, Edge, Firefox or Safari.

    THRESH sets the level above which the signal is turned down; RATIO how much; KNEE softens the onset around the threshold; ATTACK and RELEASE how fast gain reduction grabs and lets go; MAKEUP trims the output; MIX blends the compressed sound back with the dry signal (parallel compression at low settings). The curve shows input level in, output level out, with a moving dot for what's playing right now; the meter on the right shows input, output and gain reduction (GR, from the top). Click a knob's value to type one. Space plays the source.
